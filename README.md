一套面向小学三至六年级、从零起步的免费电脑启蒙教程。把新版《信息科技》教材里被淡化的**电脑基础操作**补回来。

**八辑 · 39 课 · 两种形态 · 零依赖离线可用**

**在线自学版**：双击 `index.html`。

想大规模分发：把整个 `电脑第一课` 文件夹拷到 U 盘或共享盘，整站一起拷，别只拷单个 html。

## 想改内容，改哪里

| 想改什么 | 改哪个文件 |
|---|---|
| 某一课的文字、图解 | 直接改 `lesson/` 下对应的 `.html`，用记事本就能改 |
| 课程标题、全站目录、辑次说明 | `assets/app.js` 开头的 `SITE` 数据块 |
| 配色、字号、圆角、间距 | `assets/style.css` 开头的 `:root` 变量 |
| 站点名、logo | 各页顶栏的 `.brand` 部分 |
| 讲义版配色 | 讲义是自包含的，改 `jianyi/` 里各文件开头的 `:root`（蓝青系）即可 |

> 讲义版由站点课页自动生成（正文抽取 + 蓝青系外壳）。若改了 `lesson/` 的内容，需要重新生成讲义以保持同步。生成脚本未随本仓库分发 —— 日常小改可直接手工编辑 `jianyi/` 下对应文件；需要整站重出时可联系作者索取生成脚本。

## 四个机制说明

**一、两个学段。** 页面右上角可切换「🌱 三四年级 / 🚀 五六年级」。原理是给元素加 `data-stage="low"` 或 `data-stage="high"`，CSS 按当前学段自动显隐。不带该属性的内容两个学段都显示。

**二、学习进度。** 学生的自评打勾、已学标注存在浏览器本地（localStorage），不上传、不联网。同一台电脑同一浏览器才有记忆。

**三、离线自足。** 全站没有任何外部图片、字体、脚本引用。所有图解都是内嵌 SVG 手绘，断网、无网络环境（如机房内网）都能正常使用。

**四、两种形态。** 站点页与讲义版共用同一套内容与配色体系（同为蓝青系）。讲义版是单文件自包含的：把 `jianyi/` 里任意一个 html 单独发给学生，双击就能看，不依赖其它文件。内容改动后需重新生成讲义（见上面「想改内容」）。

## 红线

1. 不含真实学生姓名、照片、账号、成绩，案例人物全部虚构。
2. 正文不出现任何需要下载、付费、注册的软件与网站。
3. 外部资源链接只集中在 `teacher.html` 一页，不让孩子直接跳转。
4. 全部内容原创；旧版课程纲要仅作框架参考，未搬运任何平台的原文与截图。
