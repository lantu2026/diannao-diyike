📌这门课是什么 / 不是什么

✓ 它是什么

  • 把被新版教材「淡化」的电脑基础操作补回来
  • 一门课同时挂两条线：技能线（今天学会什么操作）+ 素养线（今天明白什么道理）
  • 一课时 = 五分钟阅读 + 一个看得见的成果
  • 校本的、免费的、离线的、可修改的

✗ 它不是什么

  • 不替代《信息科技》教材——它是配套的练习与补充
  • 不追求讲深原理——原理交给新课标，操作留给这门课
  • 不是刷题平台，不考试、不排名、不收数据
  • 不搬运任何平台的图文，全部原创重写
🧩四种用法，按需取用
场景怎么用建议时长
信息科技课补充新课标单元上完后，用对应课次做操作练习与巩固。三年级「在线学习与生活」配第一、二辑。每课 15—20 分钟
创客社团入门社团招新后先过第一、二辑，把「会用电脑」这件事补齐，再进入第七辑图形化编程。2—3 次活动
课后服务课程包按辑推进，一辑一个周期。学生自读自练，教师只做答疑和验收。一辑 4—5 周
家校共育把这一页或某一课发给家长，让家长陪孩子练。家长不用懂电脑，照着步骤陪就行。每周 1—2 课
🖨️两种版本：在线版与讲义版
版本特点适合
在线版

怎么打印：打开讲义后按 Ctrl+P，页面会自动隐藏按钮与导航、只留正文；投屏前先选好学段即可。
⏱️第一辑课时安排建议（共 5 课 / 2—3 课时）
课时内容课堂流程（以 40 分钟计）
第 1 课时
认识伙伴		 第 1 课 电脑家族点名啦 导入 5′（提问：电脑里都有什么？）→ 共读 + 看图 8′ → 动手做 12′ → 闯关 + 自评 8′ → 小结 7′
第 2 课 开机、睡眠、关机 复习开机流程 5′ → 共读 5′ → 演示关机全流程 8′ → 学生实操 + 互查 12′ → 立班级公约 10′
第 2 课时
指挥电脑		 第 3 课 鼠标的五个魔法 五个魔法逐个演示 10′ → 学生跟做 10′ → 「回收站找还原」闯关 10′ → 交流「点错了怎么办」10′
第 4 课 键盘大冒险 坐姿口诀 + 手势示范 8′ → 手指归位练习 12′ → 闭眼找键游戏 12′ → 高段加练快捷键 8′
第 3 课时
输出成果		 第 5 课 打出第一行字 切换输入法 5′ → 打字练习 15′ → 完成「第一句签名」 12′ → 展示互评 + 本辑小结 8′
弹性建议：如果一周只有一节信息科技课，可以把第一辑摊到 4—5 周，每节课前 10 分钟安排一课，剩下的时间照常上教材内容。新课标讲「为什么」，这门课练「怎么做」，正好一前一后。
📊评价量表（可直接用）

不建议打分排名。建议用「做到了 / 还差一点 / 需要帮助」三档，由学生自评为主、同伴互评为辅、教师抽验。

维度 观察点 做到了 还差一点 需要帮助
操作技能 能否在无人帮助下完成本课的核心操作（正确开关机 / 五种点击 / 手指归位 / 打出带标点的句子） 独立完成提醒后完成需手把手示范
表达说明 能否用自己的话说出「为什么这么做」（为什么要等关机、为什么会弹出菜单、为什么标点要用中文的） 说得清楚能说一半说不出来
习惯安全 坐姿与用眼距离；关机前等待；不随意点击不明弹窗；不擅自拔插电源 每次做到偶尔忘记经常忘记
合作分享 闯关环节能否与同伴互相检查、指出问题时说得友善 主动帮忙愿意配合不参与
🛠️技术使用说明
  1. 怎么打开：把整个 电脑第一课 文件夹拷到电脑上，双击 index.html 即可。用任何浏览器都行。
  2. 要不要联网：不需要。整站所有图解都是内嵌绘制的，没有任何外部图片、字体和脚本，断网也能正常打开。
  3. 怎么分发给学生：整个文件夹拷到机房每台机器、或放到班级共享盘。文件不大，U 盘一次就能拷完。
  4. 进度存在哪：学生的自评打勾、已学标注，都只存在本机浏览器里，不会上传到任何地方。换一台电脑就重新开始——这既是隐私保护，也提醒我们它是「一次性」的。
  5. 想改内容：用记事本打开对应的 .html 文件就能改文字；改颜色和排版改 assets/style.css；改课程标题和目录改 assets/app.js 开头的站点数据。欢迎按自己学校的情况本地化。
  6. 想印成纸质：在课页上按 Ctrl + P，本站已写好打印样式，会自动隐藏导航、只留正文。也可以等 Word 版做好后直接印发。
🌱关于「两个学段」

同一个课页里，内容分了两层。页面右上角的「🌱 三四年级 / 🚀 五六年级」按钮一按，文字就会切换：

  • 🌱 三、四年级：只要求「会用」。步骤写得更细，动词更具体，图解里不出现「输入设备」「全角」这类术语。
  • 🚀 五、六年级：加一层「为什么」和「还能怎么做」。会引入分类概念、快捷键组合、标点规范，动手任务也更开放。

因此，同一个班上的两个孩子可以各看各的，你不用准备两份教案。切换结果会记住，下次打开还是他上次选的那一档。

🛡️贯穿全站的四条红线
请老师和家长监督

1. 不含真实学生信息。全部案例人物（蓝兔、巴迪，以及后续各辑将出现的虚拟小伙伴）均为虚构，不出现真实姓名、照片、账号、成绩。

2. 不引导下载安装。正文中不出现任何需要下载、付费、注册的软件和网站。

3. 不渲染恐惧。涉及网络安全的内容，以「识别与求助」为主，不吓唬孩子。

4. 外部链接集中管理。所有外链只出现在本页，不由孩子直接跳转。
